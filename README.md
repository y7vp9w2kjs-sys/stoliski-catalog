# StoliSki – קטלוג דירות ואל טורנס

קטלוג מקומי של 32 הדירות מ-Hostfully: תמונות, נתונים, סידור מיטות, אמניטיז, מפה, השוואה והערות אישיות.

## שימוש

פותחים את `index.html` בדפדפן (דאבל-קליק). לא צריך שרת ולא אינטרנט — חוץ מתצוגת המפה (אריחי OpenStreetMap).

- **כרטיסים / טבלה / מפה** — שלוש תצוגות על אותו סינון.
- **סינון** — רזידנס, מספר אורחים, מספר מיטות, מאפיינים (Ski-in/out, מרפסת, מדיח…), מפורסם באתר או לא.
- **דירה** — לחיצה על כרטיס פותחת גלריה מלאה (חצים / מקשי חצים) + כל הפרטים. "קודם/הבא" מדפדף בין הדירות שבסינון.
- **השוואה** — "+ השווה" על עד 4 כרטיסים → "השווה" בפס התחתון.
- **ההערות שלי** — שדה טקסט חופשי לכל דירה, נשמר ב-localStorage של הדפדפן (לא בקובץ).

## מבנה

```
index.html            התצוגה (קובץ אחד, ללא תלויות מלבד Leaflet למפה)
data/apartments.json  הנתונים המנורמלים – דירה אחת = רשומה אחת
data/apartments.js    אותו דבר, עטוף ב-window.APARTMENTS (כדי שיעבוד מ-file://)
images/<דירה>/NN.jpg  התמונות (423 תמונות, ~68MB)
build/build_data.py   סקריפט הבנייה: raw → apartments.json + הורדת תמונות
build/raw/            הייצוא הגולמי מ-Hostfully
```

## רענון הנתונים מ-Hostfully

**שתי פקודות, בלי התחברות ובלי דפדפן:**

```bash
python3 build/fetch_public.py
python3 build/fetch_unpublished.py
python3 build/build_data.py build/raw/raw_all.json
```

הראשונה מושכת את כל הדירות מה-API הציבורי של Hostfully (כל הדירות מפורסמות שם, אז הוא מחזיר את אותן תמונות ותיאורים כמו ממשק הניהול). השנייה מנרמלת, מתרגמת לעברית, מחשבת דירוג ומורידה תמונות חדשות.

אחר כך:

```bash
git add -A && git commit -m "Refresh catalog" && git push
```

### דירות שלא פורסמו באתר ההזמנות
`fetch_public.py` מביא רק דירות **שמפורסמות** באתר. דירה שנוספה ל-Hostfully ולא פורסמה לא תגיע דרכו.
`fetch_unpublished.py` מוסיף אותן מרשימת UID בראש הקובץ. שני מקורות:

1. **`build/raw/unpublished_full.json`** — ייצוא מלא מממשק הניהול (תמונות, תיאור, ציוד, מ״ר). אם הקובץ קיים, הוא מנצח.
2. **ה-API הציבורי** — רק נתוני ליבה ותמונת שער. רשומות כאלה מסומנות `dataPartial` ומוצגות כ"טרם דורגה".

**איך מייצרים את `unpublished_full.json`:** להיות מחובר ל-Hostfully בכרום, ולבקש ממני "תמשוך את הגלריות המלאות". אני מריץ fetch מתוך הדף לכל UID ומוריד את התוצאה.

**כשנוספת דירה ל-Hostfully:** להוסיף את ה-UID שלה ל-`UIDS` בתוך `build/fetch_unpublished.py`. ברגע שהיא תפורסם באתר, למחוק אותה משם — `fetch_public.py` יביא אותה מלאה.

**חשוב:** הקטלוג הוא צילום מצב — הוא **לא** מתעדכן לבד. אם החליפו תמונות או תיאורים ב-Hostfully, צריך להריץ את הרענון.

### מה קורה כשמשתנה ניסוח באתר
`build/hebrew.py` עובד לפי חוקים. ניסוח שהוא לא מכיר מודפס בבנייה כ-`UNTRANSLATED` במקום להופיע באנגלית בשקט — זה הסימן להוסיף חוק.

### שדות שה-API הציבורי לא מחזיר
גודל במ״ר נשלף מתוך טקסט התיאור, וסידור מיטות נלקח מהגרסה האחרונה ב-git אם האתר הסיר אותו. כלומר **צריך לעשות commit אחרי כל רענון מוצלח** — זה מה שמשמר את הנתונים האלה לרענון הבא.

## דירוג (ירוק / כתום / צהוב)

`build/scoring.py` מחשב ניקוד לכל דירה; הספים נקבעים אוטומטית כך שהמלאי מתחלק בערך לשלישים.

| קריטריון | משקל | מקור |
|---|---|---|
| מצב הדירה (1–5) | ×3 — הכי חשוב | `data/manual.json` (הערכה מהתמונות, ניתן לעריכה) |
| מיטות | זוגית אמיתית +2, יחיד +1, 2+ ספות נפתחות −1 | Hostfully |
| צפיפות | −1 רק אם פחות מ-4.3 מ״ר לאדם | Hostfully |
| מרפסת / מדיח / טלוויזיה | +0.5 כל אחד | Hostfully |
| מיזוג / כביסה / מעלית / קפה | +0.5 סה״כ | Hostfully |

**לשנות דירוג של דירה:** לערוך `condition` ב-`data/manual.json` ולהריץ `python3 build/build_data.py build/raw/raw_all36.json --skip-images`. שם גם שדה `price` (טקסט חופשי) שמוצג בדף הדירה, בטבלה ובהשוואה.
