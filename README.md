# StoliSki – קטלוג דירות ואל טורנס

קטלוג מקומי של 32 הדירות מ-Hostfully: תמונות, נתונים, סידור מיטות, אמניטיז, מפה, השוואה והערות אישיות.

## שימוש

פותחים את `index.html` בדפדפן (דאבל-קליק). לא צריך שרת ולא אינטרנט — חוץ מתצוגת המפה (אריחי OpenStreetMap).

- **כרטיסים / טבלה / מפה** — שלוש תצוגות על אותו סינון.
- **סינון** — רזידנס, מספר אורחים, מספר מיטות, מאפיינים (Ski-in/out, מרפסת, מדיח…), מפורסם באתר או לא.
- **דירה** — לחיצה על כרטיס פותחת גלריה מלאה (חצים / מקשי חצים) + כל הפרטים. "קודם/הבא" מדפדף בין הדירות שבסינון.
- **השוואה** — "+ השווה" על עד 4 כרטיסים → "השווה" בפס התחתון.
- **ההערות שלי** — שדה טקסט חופשי לכל דירה, נשמר ב-localStorage של הדפדפן (לא בקובץ).

## מבנה

```
index.html            התצוגה (קובץ אחד, ללא תלויות מלבד Leaflet למפה)
data/apartments.json  הנתונים המנורמלים – דירה אחת = רשומה אחת
data/apartments.js    אותו דבר, עטוף ב-window.APARTMENTS (כדי שיעבוד מ-file://)
images/<דירה>/NN.jpg  התמונות (423 תמונות, ~68MB)
build/build_data.py   סקריפט הבנייה: raw → apartments.json + הורדת תמונות
build/raw/            הייצוא הגולמי מ-Hostfully
```

## רענון הנתונים מ-Hostfully

1. להתחבר ל-Hostfully בכרום ולפתוח עמוד של דירה כלשהי.
2. להריץ בקונסול את הסקריפט ששולף לכל UID את
   `/api/v3.2/properties/{uid}`, `/api/internal/property-descriptions`, `/api/v3.2/photos`, `/api/v3.2/amenities`
   ולשמור את התוצאה כ-`build/raw/raw_all32.json` (רשימת ה-UIDs נמצאת בקובץ הקיים).
3. `python3 build/build_data.py build/raw/raw_all32.json`

הסקריפט מסיר קודי key-box ופרטי Wi-Fi ולא כותב אותם לשום קובץ.

## הערות על הנתונים (כפי שהם ב-Hostfully)

- 24 דירות מפורסמות באתר הציבורי; 8 לא (Cusco E10/F4, La Vanoise 154, Lauzières 003/521/612, Machu 514, Pichu 705). מסומנות "לא באתר".
- Lauzières 003 נושאת ב-Hostfully את הקוד LEZ-521 (שוכפלה מ-521); בקטלוג תוקן ל-LEZ-003.
- Cusco E10 מקושרת ב-Hostfully לדף הציבורי של Cusco E18.
- Cusco E19 ו-F4 מוקמו ב-Hostfully 10 ק"מ מחוץ לעיירה; בקטלוג כל היחידות של רזידנס מקבלות את הקואורדינטה של הבניין.
- Sérac K10 היא היחידה הגדולה באמת (75 מ"ר, 7 אורחים); כל השאר 20–26 מ"ר.

## דירוג (ירוק / כתום / צהוב)

`build/scoring.py` מחשב ניקוד לכל דירה; הספים נקבעים אוטומטית כך שהמלאי מתחלק בערך לשלישים.

| קריטריון | משקל | מקור |
|---|---|---|
| מצב הדירה (1–5) | ×3 — הכי חשוב | `data/manual.json` (הערכה מהתמונות, ניתן לעריכה) |
| מיטות | זוגית אמיתית +2, יחיד +1, 2+ ספות נפתחות −1 | Hostfully |
| צפיפות | −1 רק אם פחות מ-4.3 מ״ר לאדם | Hostfully |
| מרפסת / מדיח / טלוויזיה | +0.5 כל אחד | Hostfully |
| מיזוג / כביסה / מעלית / קפה | +0.5 סה״כ | Hostfully |

**לשנות דירוג של דירה:** לערוך `condition` ב-`data/manual.json` ולהריץ `python3 build/build_data.py build/raw/raw_all32.json --skip-images`. שם גם שדה `price` (טקסט חופשי) שמוצג בדף הדירה, בטבלה ובהשוואה.
